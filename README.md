# SSU_FamilyAccountBook

## 🔖 커밋 컨벤션
커밋에 해당하는 커밋 메시지 쓰기 (예: feat. 이슈내용 )


| Message  | 설명                                              |
| :------: | :------------------------------------------------ |
|   feat   | 새로운 기능 추가                            |
|  fix   | 버그 수정 |
|  refactor  | 코드 리펙토링 |
| comment | 주석 추가 및 변경                                     |
|  rename   | 파일 혹은 폴더명 수정                |
|  remove   | 파일 혹은 폴더 삭제                |
|  chore   | 기타 변경사항                |





## Git 이슈 연결 가이드

### 커밋 메시지

**작업 진행 중** (이슈 열린 상태 유지)
```bash
git commit -m "feat: 기능 구현 ref #이슈번호"
```

**작업 완료** (PR merge 시 이슈 자동 닫기)
```bash
git commit -m "feat: 기능 완료 closes #이슈번호"
```

### 키워드 정리

| 키워드 | 효과 | 사용 시점 |
|--------|------|----------|
| `ref #N` | 이슈 언급만 | 작업 진행 중 |
| `related to #N` | 이슈 언급만 | 작업 진행 중 |
| `closes #N` | merge 시 이슈 닫기 | 작업 완료 |

### 주의사항
- 키워드와 `#` 사이 **띄어쓰기 필수**: `closes #7` ✅ / `closes#7` ❌
