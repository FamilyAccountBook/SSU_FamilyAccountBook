# SSU_FamilyAccountBook

## 🔖 커밋 컨벤션
커밋에 해당하는 커밋 메시지 쓰기 (예: feat. 이슈내용 )


| Message  | 설명                                              |
| :------: | :------------------------------------------------ |
|   feat   | 새로운 기능 추가                            |
|  fix   | 버그 수정 |
|  refactor  | 코드 리펙토링 |
| comment | 주석 추가 및 변경                                     |
|  rename   | 파일 혹은 폴더명 수정                |
|  remove   | 파일 혹은 폴더 삭제                |
|  chore   | 기타 변경사항                |

커밋 메시지 (이슈 번호 활용)
코드를 수정하고 커밋(commit)할 때, 메시지 끝에 이슈 번호를 적습니다.


'''
git add .
git commit -m "feat: 로그인 UI 레이아웃 완성 (#3)"
'''
